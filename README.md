# Smart Money Guide

A static, three-page personal-finance information website ready for Netlify.

## Deploy
Drag this folder into Netlify Drop, or connect the repository. No build command is required.

## Ad integration
Replace the contents of `.ad-slot` containers with your approved Google AdSense snippets when ready. Keep the container spacing and never place ads over content.

## Notes
The contact form is intentionally a front-end demo. Connect it to Netlify Forms or another form provider before launch.
